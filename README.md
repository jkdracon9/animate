# animate

태블릿(갤럭시 탭 S6 Lite + S펜 기준)에서 쓰는 프레임 애니메이션 웹앱입니다.
설치 없이 브라우저에서 실행되고, 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

**주소:** https://jkdracon9.github.io/animate/

## 태블릿에 앱으로 설치하기

1. 태블릿 **Chrome**에서 위 주소를 엽니다. 카카오톡이나 네이버 앱 안의 브라우저는 안 돼요.
2. 오른쪽 위 **⋮** → **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
   - 삼성 인터넷: 아래 **≡** → **현재 페이지 추가** → **홈 화면**
3. 홈 화면의 **animate** 아이콘으로 열면 주소표시줄 없이 전체 화면으로 실행됩니다.
4. 한 번 연 뒤에는 인터넷이 없어도 실행됩니다.

## 기능

| 구분 | 내용 |
|---|---|
| 프로젝트 | 여러 작품 관리(갤러리), 이름 변경, 복제, 삭제, 자동 저장 |
| 캔버스 | 크기 프리셋(가로/세로 쇼츠/정사각 등)과 직접 입력, 배경색, 크기 변경(맞추기/늘리기/자르기) |
| 도구 | 브러시(펜·연필·마커·에어브러시), 지우개, 채우기, 스포이트, 도형(직선·사각형·원), 이미지 가져오기 |
| 브러시 설정 | 크기, 불투명도, 손떨림 보정, S펜 필압 |
| 색 | 색상 선택기, 기본 팔레트 30색, 최근 사용 색 |
| 레이어 | 추가·복제·삭제·합치기·순서 변경·숨기기·잠금·불투명도·이름 변경 (최대 16개) |
| 프레임 | 추가·복제·삭제·복사/붙여넣기·순서 이동·프레임 길이(×1~×99) |
| 어니언 스킨 | 이전/다음 프레임 수(0~3), 진하기, 색 구분 |
| 재생 | FPS 1~60, 반복 재생 |
| 보조 | 격자(간격 선택, 3등분), 화면 맞추기, 확대/이동 |
| 내보내기 | **MP4**(H.264), GIF, PNG 묶음(ZIP), 현재 프레임 PNG, 해상도 0.5/1/2배, 공유 또는 기기에 저장 |

## 조작법

| 동작 | 기능 |
|---|---|
| S펜으로 그리기 | 그리기 (S펜이 감지되면 자동으로 *펜 전용* 모드가 켜짐) |
| S펜 버튼을 누른 채 그리기 | 지우개 |
| 두 손가락 벌리기/모으기, 끌기 | 확대·축소, 이동 |
| 두 손가락 탭 | 실행취소 |
| 세 손가락 탭 | 다시실행 |
| 선택된 도구를 한 번 더 누르기 | 도구 설정(브러시 종류, 도형 종류 등) |
| 🧅 또는 # 길게 누르기 | 어니언 스킨, 격자 설정 |
| 레이어 길게 누르기 | 레이어 이름 바꾸기 |

PC 단축키: `Ctrl+Z` / `Ctrl+Y`, `Space` 재생, `B` 브러시, `E` 지우개, `G` 채우기, `I` 스포이트, `U` 도형, `←` `→` 프레임 이동

## 저장 위치

작품은 **그 기기 브라우저 안(IndexedDB)**에 저장됩니다. 서버로 올라가지 않아요.
Chrome의 사이트 데이터를 지우면 작품도 지워지니, 중요한 작품은 MP4나 PNG로 내보내 두세요.

## 개발

```
python server.py
```

PC에서 `http://localhost:8080`으로 확인합니다. 빌드 과정이나 외부 라이브러리는 없습니다.
GitHub의 `main` 브랜치에 올리면 GitHub Pages에 자동으로 반영됩니다.
