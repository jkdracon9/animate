# animate

태블릿(갤럭시 탭 S6 Lite + S펜 기준)에서 쓰는 프레임 애니메이션 웹앱입니다.
설치 없이 브라우저에서 실행되고, 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

**주소:** https://jkdracon9.github.io/animate/

## 태블릿에 앱으로 설치하기

1. 태블릿 **Chrome**에서 위 주소를 엽니다. 카카오톡이나 네이버 앱 안의 브라우저는 안 돼요.
2. 오른쪽 위 **⋮** → **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
   - 삼성 인터넷: 아래 **≡** → **현재 페이지 추가** → **홈 화면**
3. 홈 화면의 **animate** 아이콘으로 열면 주소표시줄 없이 전체 화면으로 실행됩니다.
4. 한 번 연 뒤에는 인터넷이 없어도 실행됩니다.

## 기능

| 구분 | 내용 |
|---|---|
| 작품 | 여러 작품 관리, 이름 변경, 복제, 삭제, 자동 저장 |
| 화면 | 가로 HD(1280×720) / 세로 HD(720×1280), 배경색, 방향 바꾸기(맞추기/늘리기/가운데만) |
| 빠르기 | FPS 4·6·8·12·24·30 (쉬운 설명 포함), 직접 입력 1~60 |
| 도구 | 붓(펜·연필·마커·스프레이), 지우개, 채우기, 도형(직선·네모·동그라미), 글자, 골라서 옮기기, 색 뽑기, 사진 넣기 |
| 골라서 옮기기 | 자유/사각형 선택, 옮기기·크기·회전, 좌우/상하 뒤집기, 복사·잘라내기·붙이기(다른 장면에도) |
| 글자 | 고딕·명조·손글씨·고정폭, 크기, 굵게, 흰 테두리 |
| 붓 설정 | 굵기, 진하기, 손떨림 줄이기, S펜 필압 |
| 색 | 색상 선택기, 기본 30색, 최근 색 |
| 레이어 | 새로·복제·합치기·지우기·순서·숨기기·잠금·진하기·이름 (최대 16개) |
| 장면 | 새 장면·복제·지우기·복사/붙이기·순서 이동·보이는 시간(×1~×99) |
| 겹쳐보기 | 앞/뒤 장면 수(0~3), 진하기, 색 구분 |
| 소리 | 음악 파일 넣기, 재생하며 녹음하기, 시작 장면·소리 크기 조절, 재생할 때 함께 들림 |
| 그림판 | 두 손가락 확대·이동·회전(0°/90° 자동 맞춤), 격자 |
| 영상 만들기 | **MP4(소리 포함)**, GIF, 장면 그림 묶음(PNG), 지금 장면 그림, 해상도 0.5/1/2배, 공유 또는 기기에 저장 |

## 조작법

| 동작 | 기능 |
|---|---|
| S펜으로 그리기 | 그리기 (S펜이 감지되면 자동으로 *펜으로만 그리기*가 켜짐) |
| S펜 버튼을 누른 채 그리기 | 지우개 |
| 두 손가락 벌리기/모으기, 끌기, 돌리기 | 확대·축소, 이동, 회전 |
| 두 손가락 톡 | 되돌리기 |
| 세 손가락 톡 | 다시 하기 |
| 선택한 도구를 한 번 더 누르기 | 도구 설정(붓 종류, 도형 종류 등) |
| 🧅 겹쳐보기 길게 누르기 | 겹쳐보기·격자 설정 |
| 레이어 길게 누르기 | 레이어 이름 바꾸기 |

PC 단축키: `Ctrl+Z` / `Ctrl+Y`, `Space` 재생, `B` 붓, `E` 지우개, `G` 채우기, `I` 색 뽑기, `U` 도형, `S` 옮기기, `T` 글자, `←` `→` 장면 이동, `Enter` 옮기기 확정, `Esc` 취소
## 저장 위치

작품은 **그 기기 브라우저 안(IndexedDB)**에 저장됩니다. 서버로 올라가지 않아요.
Chrome의 사이트 데이터를 지우면 작품도 지워지니, 중요한 작품은 MP4나 PNG로 내보내 두세요.

## 개발

```
python server.py
```

PC에서 `http://localhost:8080`으로 확인합니다. 빌드 과정이나 외부 라이브러리는 없습니다.
GitHub의 `main` 브랜치에 올리면 GitHub Pages에 자동으로 반영됩니다.
